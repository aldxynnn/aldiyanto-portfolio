# Optional Offline Soundtrack Drop-In

Saat foto di **Visual Journal** dibuka, portofolio sudah otomatis memutar lagu **nissi, 25Hzz — Wyw my sweetie** melalui player bawaan (mendukung pilihan **Original** & **Slowed** serta tautan Spotify).

Jika Anda ingin memutar file audio lokal secara langsung (tanpa koneksi YouTube, dengan progress bar scrub penuh):
1. Simpan file audio Anda di folder ini (`public/audio/`) dengan nama:
   - `wyw-my-sweetie.mp3` *(mendukung `.mp3`, `.m4a`, `.ogg`, atau `.wav`)*
2. Refresh halaman — sistem akan otomatis mendeteksi dan memprioritaskan audio lokal Anda tanpa perlu ubah kode apa pun.
